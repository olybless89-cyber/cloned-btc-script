About

A demo built to be looked at, not invested in

Auralis is a small full-stack sample: a landing site, real authentication and a dashboard backed by an Express API. It exists so the interface and the code can be studied, forked and modified. It is not affiliated with any real exchange or financial institution.

What's real

The authentication flow, the session handling and the API are genuinely implemented. Passwords are hashed with scrypt and never stored in plain text. Data lives in a local JSON file.

What's simulated

Every price, percentage change and volume figure is generated locally with a random walk. There is no exchange connection, no order book and no money of any kind moving through the system.

Why it's built this way

Crypto-themed sites are frequently used to dress up investment fraud. This demo deliberately omits the elements that make those sites dangerous: promised returns, deposit flows, referral pyramids and fabricated "live investor" activity.

Stack

Node.js with Express for the API and static hosting, vanilla HTML/CSS/JavaScript on the front end, and a JSON file for storage. No build step and no external dependencies beyond Express.
