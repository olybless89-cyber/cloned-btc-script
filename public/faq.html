FAQ

Questions

Can I deposit or withdraw money?
No. There is no deposit flow, no wallet connection and no payout. The only balance in the app is a virtual $10,000 that you can reset at any time.
Are the prices real?
No. Prices are generated locally with a random walk so the dashboard has something to animate. They are not connected to any exchange or data provider and should never be used for decisions about real assets.
Do you offer investment plans with returns?
No, and that is deliberate. Promising a fixed percentage return over a short period is the defining feature of a Ponzi or HYIP scheme. This demo does not model that, and the pricing page is a layout example only.
Disclaimer
This application is a non-functional demonstration. It provides no financial advice and no financial service. Nothing in it constitutes an offer or solicitation to buy or sell any asset. All market data is simulated. Use it for learning and interface practice only.
What happens to my data?
Accounts you create are stored in a local data/store.json file on the machine running the server. Passwords are hashed with scrypt. If you are using a hosted copy of this demo, treat any account you create as disposable and do not use a password you rely on elsewhere.
Can I run it myself?
Yes. Install dependencies and start the server — see the README in the repository. It needs only Node.js 18+ and Express.
